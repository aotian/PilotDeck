最终客观题 1—4

  1. 模拟法解决问题时，最先应明确什么？
  2. 0上1右2下3左时，顺时针转向可写dir=(dir+1)%4。
  3. 模拟程序只测试普通数据即可，边界状态不影响答案。
  4. 访问n行m列矩阵所有元素，正确循环范围是？
  1. A：模拟的核心是定义状态、操作和更新顺序。
  2. T：加1并取模形成循环方向。
  3. F：初始即结束、越界、并列等边界常决定正确性。
  4. A：行下标0到n-1，列下标0到m-1。

最终客观题 5—8

  1. 顺时针旋转时，原位置(i,j)常映射到？
  2. 访问相邻格前必须先判断新行列是否在矩阵范围内。
  3. 计算较大整数的精确平方时，可以始终放心地用`pow(x,2)`代替`x*x`。
  4. 表达式`(double)7/2`的值是（ ）。
  1. A：新行来自原列，新列由原行反向得到。
  2. T：否则可能数组越界。
  3. F：`pow`使用浮点运算，精确整数运算优先使用整数乘法并注意溢出。
  4. C：先把7转为double，再进行浮点除法。

最终客观题 9—12

  1. 递归函数必须有可达的终止条件，并且每次调用应更接近终止条件。
  2. 函数声明`int f(int x);`能够告诉编译器什么？
  3. 字符数组`char s[]="cat";`的`strlen(s)`是（ ）。
  4. 判断两个C风格字符串内容是否相等，应使用（ ）。
  1. T：这是递归能够停止的两个基本条件。
  2. A：声明提供函数签名，使调用处能够通过编译。
  3. B：有效字符3个，结尾\0不计入长度。
  4. C：strcmp返回0表示内容相等。

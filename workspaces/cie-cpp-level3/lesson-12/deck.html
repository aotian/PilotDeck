值传递 int x

把实参的值复制给形参；函数内修改x，不改变原变量

引用传递 int &x

形参是实参的别名；修改x会直接修改原变量

何时用引用

交换数据、返回多个结果、避免复制大对象

风险

引用会产生副作用，调用前要知道哪些变量可能改变

void swap2(int &a, int &b) { int t=a; a=b; b=t; }
教师提示引用符号写在形参类型后。

int a[100] = {};        // 全部初始化为0
for (int i=0; i<n; ++i) cin >> a[i];

合法下标：长度为n时只能访问0到n-1。循环条件写成i<n，不是i<=n。

最值初始化可用第一个有效元素，避免用0导致全负数据错误。

  1. 函数声明`int f(int x);`能够告诉编译器什么？
  2. 引用参数可以让函数直接修改调用者传入的变量。

  4. 字符数组`char s[]="cat";`的`strlen(s)`是（ ）。
  1. A：声明提供函数签名，使调用处能够通过编译。
  2. T：引用形参是实参对象的别名。
  3. B：终止条件与规模缩小缺一不可。
  4. B：有效字符3个，结尾\0不计入长度。

模考二客观题 9—12

  1. 访问n行m列矩阵，合法下标是（ ）。
  2. 表达式`5/2`与`(double)5/2`的结果分别是（ ）。
  3. 循环`for(int i=0;i<=n;i++) a[i]=0;`中，若数组长度为n，错误是（ ）。
  4. 提交程序前最有效的检查组合是（ ）。
  1. A：行下标小于n，列下标小于m。
  2. A：前者是整数除法，后者是浮点除法。
  3. B：合法下标为0到n-1。
  4. B：不同类型数据能暴露不同错误。

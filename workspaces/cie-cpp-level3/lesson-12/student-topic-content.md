## 一、函数板书

### 1. 定义、声明、调用

函数是完成一个明确任务、可以重复调用的代码块。调用前，编译器必须先看到函数声明或定义。

```cpp
返回类型 函数名(参数表);
返回类型 函数名(参数表) {
    // 函数体
    return 返回值;
}
```

- **值传递**：形参得到实参的副本，修改形参不影响实参。
- **引用传递**：形参写成 `类型 &名称`，它是实参的别名，修改会影响原变量。
- **return**：结束函数并返回结果；非 `void` 函数的所有路径都应返回合法值。
- **函数重载**：同名函数必须具有不同参数列表，不能只靠返回类型区分。

## 二、递归板书

递归是函数直接或间接调用自己。可靠递归必须同时具备：

1. **终止条件**：最小问题直接返回；
2. **规模缩小**：每次调用都更接近终止条件；
3. **返回关系**：当前层利用子问题结果得到自己的结果。

```cpp
int sum(int n) {
    if (n == 0) return 0;
    return n + sum(n - 1);
}
```

跟踪递归时分成“向下调用”和“向上返回”，不要跳着猜。

## 三、字符数组与常用函数

字符数组以 `'\0'` 表示字符串结束。长度为 `n` 的数组，下标是 `0..n-1`；若用来保存字符串，必须为 `'\0'` 留一个位置。

| 头文件 | 函数 | 含义 | 关键易错点 |
|---|---|---|---|
| `<cstring>` | `strlen(s)` | 有效字符数 | 不包含 `'\0'` |
| `<cstring>` | `strcpy(dst,src)` | 复制字符串 | 目标容量必须足够 |
| `<cstring>` | `strcat(dst,src)` | 拼接字符串 | 容量至少为两串长度之和加1 |
| `<cstring>` | `strcmp(a,b)` | 比较字符串内容 | 返回0才表示相等 |
| `<cctype>` | `isdigit(ch)` | 是否为数字字符 | 不是判断整数变量 |
| `<cctype>` | `isalpha(ch)` | 是否为字母 | 可与大小写判断组合 |
| `<cctype>` | `tolower/toupper` | 大小写转换 | 要接收返回值 |

## 四、数学函数与类型

| 函数 | 含义 | 注意 |
|---|---|---|
| `sqrt(x)` | 平方根 | 返回浮点值，整数结论要再次验证 |
| `pow(a,b)` | a的b次幂 | 返回浮点值，注意精度 |
| `floor/ceil` | 向下/向上取整 | 与强制转整数不同 |
| `round(x)` | 四舍五入 | 返回最接近的整数值 |
| `abs(x)` | 绝对值 | 根据参数类型选择重载 |

`5/2` 是整数除法，结果为2；`(double)5/2` 才得到2.5。乘法可能溢出时使用 `1LL*a*b`。

## 五、数组、枚举与模拟

- 一维数组长度为 `n` 时，合法下标是 `0..n-1`。
- 二维数组先确定 `n行m列`；访问相邻格前先判断坐标合法。
- 枚举法先确定不重不漏的候选范围，再逐个验证；可用 `i<j<k` 去重。
- 模拟法先定义状态，再按事件顺序更新；要说明使用旧状态还是新状态。

## 六、提交前检查

1. 能否编译：头文件、分号、括号、函数声明；
2. 输入是否完整：数量、类型、整行与空格；
3. 边界是否合法：循环、数组、递归终止；
4. 类型是否安全：整数除法、long long、浮点验证；
5. 输出是否严格：顺序、空格、换行、大小写；
6. 是否测过：最小、普通、边界、特殊和随机小数据。
